# Executed before/after mechanism casebook

This is a **new authored synthetic demonstration**, not an excerpt from the 100/300-paper cohorts. The supplied manuscript and review-style feedback were written for explanation. There are no review scores or new scientific measurements. The outputs were generated by the actual adapters in `method/`; model-backed adapters used MiniMax-M3 (China region) and the other controls ran locally. Input utility values intentionally favor a cheap irrelevant passage to expose sensitivity to misspecified estimates. This demonstration is not a cost-matched efficacy comparison.

## Inspect the artifacts

- `input.json`: fixed authored manuscript, review-style feedback, candidates, budget and feedback.
- `outputs.json`: all ten registered controls and three EvidencePatch variants, plus four boundary situations.
- `execution.json`: aggregate API usage, including retry/resume attempts. No API credentials or raw request ledger is published.
- `edit_surfaces.json`: **manually authored** prose-rewrite and cross-reference illustrations, not evaluated adapter outputs.
- `index.html`, `pages/`: screenshot source pages and individual method views.
- `screenshots/`: actual Chromium full-page captures of those HTML pages. Markdown text is displayed verbatim, with explicit excerpt markers where needed. This is an artifact viewer, not a screenshot of a third-party review service.

[Read the live casebook](https://fengxianji.github.io/FXJ-BLOG/assets/revision-casebook/index.html).

## Rebuild without new model calls

```bash
python3 scripts/build_revision_casebook.py
# Optional browser tooling for screenshots (Node.js required):
npm install --no-save playwright
npx playwright install chromium
node scripts/screenshot_revision_casebook.cjs
```

`build_revision_casebook.py` reads the saved outputs. The original screenshot run used Playwright/Chromium available in the working environment. Browser versions and fonts may affect pixels, not the underlying saved text.

To run missing offline controls only: `python3 scripts/run_revision_casebook.py`. It resumes saved methods. To execute model-backed methods on a fresh version, supply a private config and explicit `--allow-api`; do not alter this frozen input under an existing output hash. A model rerun may differ. The CLI caps calls in each invocation, uses the configured provider retries, and records usage under ignored `local_runs/`.

## What the saved output demonstrates

- Retrieval emits the exact but irrelevant RGB passage for a label-noise concern.
- Cost-greedy selects this distractor under the deliberately favorable input utility/cost.
- Random and estimated-utility oracle select the seed; all-feasible selects learning rate.
- One-shot, iterative and DRPG-style generation all acknowledge that label-noise experiments were not run.
- All three EvidencePatch variants reject the RGB candidate and select seed within budget. The learning-rate candidate is assessed selectable but deferred.
- An empty candidate set produces abstention. A wrapper applies the existing lexical provenance filter before the bad-quote case. A separate cost/budget check rejects a cost-1 action at budget 0.

None of these outputs establish an efficacy advantage over a paper population. The missing-experiment case has no candidate because the authored input lacks result support, not because an independent expert certified its diagnosis.
